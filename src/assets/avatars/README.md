# Avatars

Profile photos for testimonials / people on the site (Success Stories, etc.).

Drop images here (square, webp or png preferred, ~200×200 or larger). Name each
file after the person or a stable slug, e.g. `jordan-r.webp`, `priya-s.webp`.

To use one on a testimonial, import it in `src/pages/SuccessStories.js` and add
an `avatar` field to that person's entry; the card will show the photo instead
of the generated initials.
