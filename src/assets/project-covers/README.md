# Project covers

Drop project cover images here (webp preferred, ~800×600 or larger, landscape).

Name each file after the project slug so it maps cleanly in `src/data/projects.js`,
e.g. `taste.webp`, `westpac-app.webp`, `home-in.webp`.

Until a real cover is added, the reel falls back to the generated placeholder
art in `src/assets/reel-placeholders/`.
